# GHub 标志

圆角 G 的连续轮廓代表接续工作，横向路径末端的圆点代表连接枢纽。主色与应用现有蓝灰界面协调；图形没有方向性，RTL 界面不镜像。

- `ghub-icon.svg`：可编辑的唯一图形源，108 × 108，包含满幅背景。
- `ghub-mark.svg`：生成的透明底深色标志，适合文档和浅色背景。
- `preview.html` / `preview.png`：圆角、圆形、主题单色及小尺寸预览。主题配色仅为示例，实际颜色由 Android 桌面决定。
- `ghub-icon-512.png`：圆角桌面图标 PNG，适合展示和分享。

颜色：背景 `#1C293D`，G 字形 `#F5F7FB`，连接节点 `#9BBDF3`；透明标志使用 `#1C293D` 和界面主色 `#4B6590`。

编辑 SVG 后运行 `python3 scripts/generate_brand.py`，同步生成 Android 自适应前景、API 33 单色层、透明通知图标、普通图标和透明 SVG。应用最低 API 29，自适应入口分别位于 `mipmap-anydpi-v26` / `mipmap-anydpi-v33`；圆形桌面使用相同自适应资源，由系统裁切。

前景位于中心 66dp 安全圆内。通知图标放大同一轮廓至 24dp 画布的约 20dp，只有白色形状和透明背景，保证系统着色后仍能识别。

`preview.html` 嵌入了生成后的 SVG，可直接在浏览器打开，无需网络或本地服务。PNG 文件是对应预览的导出。
