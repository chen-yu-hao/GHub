# 任务看板 UI 对照

`preview.html` 是使用示例数据的离线对照页，直接引用 `app/src/main/assets/taskboard` 的生产 CSS、SVG 和 JavaScript。它不连接服务器，也不会执行审批或命令。用浏览器打开此文件即可查看 632 × 840 的画布以及四种任务状态。

`supplied-board-markup.html` 是从用户提供的打包 HTML 中原样提取的看板正文，保留原始内联 CSS 与 SVG，可用于核对尺寸与图形。它包含原型模板语法，不能单独作为生产页面运行。

## 已保持的参考尺寸

- 画布 632 × 840，内边距上下 16、左右 20，区块间距 12。
- 页头 y=16，高 63；筛选行 y=91，高 44；状态栏 y=147，高 72；任务区域从 y=231 开始。
- 页脚 y=761，高 63；审批卡自然高 204，圆角 14、边框 2、内边距 12/14。
- 四类任务每页分别显示 2 / 3 / 7 / 2 项。
- 字号、行高、黑白边框、彩色/黑白状态色及 SVG 路径沿用附件。

生产页面使用当前 WebView 视口高度。632 × 840 时采用上述布局；窄屏调整间距、字号及页脚排版，任务区域在必要时滚动。正文优先使用 Noto Sans SC，然后回退到系统中文字体；附件实际封装的 JetBrains Mono 已随 App 本地打包。附件未封装中文字体文件，因此不同 Android 系统的中文字体字形可能略有差异。

示例页面固定时间为 2026-11-02 08:26，方便核对附件的“08:23 已同步”和相对时间。原附件只提供已完成第一页的 7 项；示例页额外 2 项明确标记为分页测试记录。生产页面不加载此文件夹内任何文件，不含示例任务或统计。

## 验证

在仓库根目录运行：

```sh
node scripts/taskboard/board.test.cjs
```

测试覆盖数据筛选与分页、审批确认与过期检查、离线状态、SSH-only 终端入口、部分统计、XSS 惰性文本渲染、对话框返回行为及来源于原 HTML 的 CSS/SVG 对照。CSS 几何断言不等同于浏览器截图比对或 Ocean 5C 真机验证。
