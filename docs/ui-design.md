# Android 工作台视觉与交互

## 0.1.14：终端、文件与返回体验

- 终端增加显式键盘唤起、Ctrl/Alt/Shift 修饰键和中文输入兼容设置，点击终端后自动聚焦并唤起输入法。
- SFTP 下载改为按远端文件流和大小预检读取，图片预览使用正确扩展名并在关闭时清理缓存；非文本文件不再误打开编辑器。
- 页面级编辑器和图片预览统一使用返回箭头，系统返回与页面返回保持同一层级。

## 0.1.13：兼容范围与入口收敛

- 客户端最低兼容基线为 Codex CLI / App Server 0.164.0，接受后续 0.x 版本并通过握手确认协议；不为每个 CLI 版本单独发布 Android 包。
- 版本门禁、协议 fixture、诊断信息和预览数据使用兼容范围表达；新协议能力仍需单独适配和回归。
- 行内代码使用圆角背景，与代码块保持同一套中性色表面；输入设置时，当前字段会随键盘自动滚到可见区域。

## 服务器入口职责

- 顶栏服务器图标只负责快速切换当前服务器，不提供添加或编辑操作。
- 添加、编辑、删除服务器，以及密钥、跳板机和连接配置统一位于“设置 → 服务器”。
- 首页右上角直接进入设置；会话列表在连接后自动同步，并保留下拉刷新作为即时刷新手段。
- 无服务器的空状态通过“打开设置”进入配置流程，避免“添加主机”在多个页面重复出现。
- 服务器详情只负责配置和连接管理，不提供“打开项目”；连接就绪时原位置显示“断开连接”，建立连接时显示“取消连接”，等待网络或重连时显示“停止重连”。项目从工作台首页进入。
- 设置内查看、编辑、连接其他服务器不切换当前工作台；编辑后返回原服务器详情，详情、服务器列表、设置之间保持逐级返回。删除正在查看的配置后回到服务器列表。
- 保存名称或默认目录不影响现有连接；修改地址、认证、跳板或远端服务参数时释放该服务器的旧连接，提示重新连接。只有首次添加服务器时才初始化工作台选择。

## 0.1.11：输出默认折叠

- 命令执行、计划、推理摘要、未知事件和失败输出默认只显示摘要行，点击后展开详情。
- 最终助手回答和用户消息保持展开，保证打开会话后可以直接阅读结论。
- 文件改动继续使用文件数与增删行摘要，具体 diff 点击后查看。

## 0.1.10：会话 Markdown 排版

- 会话答案使用工作台自己的 Markdown 主题：缩小标题层级，收紧段落、列表和引用间距，避免文档式的大留白。
- 代码块、行内代码、表格和引用使用中性色表面与细边框，适配浅色和深色模式。
- Markdown 组件限制为内容宽度，不再默认占满整张消息区域的高度。

## 0.1.7：连接恢复提示

- 检查、等待网络、重连与同步使用紧凑状态提示，保留当前页面、聊天和草稿，不重复弹断网错误。
- 连续失败或等待网络时提供立即重试；需要人工处理的认证、指纹、兼容问题保留明确错误入口。
- 恢复完成前暂停发送与审批；确认真实断线后清除旧审批，终端不因短暂的检查状态显示为断开。
- 具体恢复策略、诊断信息和验证边界见 [连接恢复](connection-recovery.md)。

## 0.1.8：会话缓存大小保护

- 本地会话缓存限制最近条目和文本大小，避免 Android SQLite `CursorWindow` 因单行过大而无法读取。
- 发现旧缓存超限时自动清理该会话缓存，从远端重新同步，不删除远端会话。

## 0.1.9：服务器切换与分片缓存

- 顶部服务器入口打开“切换服务器”面板，直接显示名称、地址、连接状态和当前选择；添加和编辑统一从设置中的“服务器”进入。
- 首页右上角使用设置齿轮，服务器切换由左上角入口负责，避免切换、添加和管理共用一个模糊入口。
- 会话缓存迁移到分片表，避免长历史、命令输出或 diff 造成 SQLite 单行过大。

## 0.1.6：输入与项目操作分开

- 输入框移除“工作区”入口，底部只保留左侧附件按钮、右侧语音与发送/停止按钮。
- 聊天顶部更多菜单直接提供项目文件、终端、返回项目列表、重命名和归档会话；会话在连接后和前台自动同步，必要时可下拉刷新。
- 附件面板只保留输入相关操作与模型选择，移除重复的会话选项入口。
- 项目目录有效时可打开文件和终端；通过切换项目工具保留当前会话，返回时可继续输入。

## 0.1.5：项目直接展开会话

- 首页顶栏显示主机与连接状态。`＋` 添加项目，右上角齿轮进入设置；没有固定底部操作栏，也没有“继续工作”重复区域。
- 项目采用 56 dp 起的普通列表行，18 dp 图标，没有卡片或图标底框。点击展开最近四条会话，查看全部可展开并继续加载远端分页。
- 会话行 48 dp 起、16 dp 图标，支持多行标题。打开后直接进入聊天，返回项目首页时保留展开状态和列表位置。
- 项目菜单提供新会话、文件、终端和重命名。搜索与归档筛选在首页底部面板内完成。
- 设置从首页右上角齿轮进入。聊天顶栏更多按钮提供会话操作，文件与终端顶栏提供工作区操作。
- 保留柔和中性色、紧凑字体和必要的 48 dp 触控范围；只为主操作与必要状态使用颜色。

## 完成提醒与已读状态

- 按主机和会话保存最近观察到的轮次、轮次状态、最近完成轮次和已读轮次。
- 只使用服务端轮次的 `completed` 状态产生“新结果”；不把线程 idle、notLoaded 或网络断开解释为完成。
- 首次观察的已完成历史建立基线，不把旧历史全部标为新结果。之后已观察会话的新完成轮次会产生提醒；同一完成事件重复到达不会重复产生计数。
- 项目显示有新结果的会话数；展开后对应会话显示“新结果”。进入前台聊天、且该轮内容已存在于当前历史时标为已读。
- 运行中、等待审批和新结果采用独立文字标识，审批优先显示。提醒记录使用 DataStore 保存，重启后可恢复。
- 前台每 20 秒同步一次最近会话，并对变化或运行中的已加载会话读取最新一轮历史（最多三个并行读取）。后台停止定时同步；重连后重新核对。搜索/归档筛选期间暂停这个列表定时同步。
- 提醒范围是已同步、已观察的会话，不保证尚未加载的全部历史或手机离线期间的即时通知。发现一个此前从未观察、已经完成的会话时仍按历史基线处理。
- 定时同步保留已加载的较早分页，显示中的执行结果以远端状态为准；没有增加远端 agent，也不通过恢复或重启任务制造提醒。

## 紧凑聊天

- 每一轮显示用户消息、执行过程摘要、最后一条助手回复和文件修改摘要。
- 普通命令、过程说明、计划和推理摘要默认收入可展开的执行过程。只有有确切结构化数据时才显示命令数、文件数和增删行数，不从自然语言猜测统计。
- 文件摘要按真实路径分组，展开后可继续展开每个文件的 diff。行数来自统一 diff 的 hunk；多次改动的数字是本轮改动记录累计，不声称等同于最终 Git diff。
- 老缓存只有格式化文本时保留原始记录入口，不编造文件统计。
- 失败记录保持可见，审批保留命令、范围及明确选择。发送状态待确认仍提示用户核对。
- 消息继续使用轮次与消息复合标识，列表分组使用独立前缀，保留 0.1.4 的重复 key 修正。

- 保留完整 GFM 文档解析，放在 Default dispatcher 上；流式解析之间等待 120ms，并合并中间更新。未完成的新快照不清空上一版结果。
- 渲染采用独立段落的数据与局部 AST 偏移；内容及语法树未变化时复用原有块。稳定的链接环境避免每个 token 更新时让全部旧段落重新标注。晚到的引用定义仍会更新引用链接。
- 保留原解析器的 LeafASTNode / CompositeASTNode 类型，兼容自动链接、嵌套列表等依赖具体节点类型的渲染。
- 顶层空行与链接定义不再各自额外生成显示块；保留段落间距。表格移除不必要的固有高度测量，继续支持换行、横向滚动、完整展开和复制。
- 这是减少重复渲染，尚未将整条长回复拆成 LazyColumn 分页块；一个特别长的单段、超大表格、公式与任意 HTML 不在本次完全解决范围内。

## 0.1.25：首页项目移除

- 项目菜单增加“从首页移除”，旁边说明保留会话和文件、可通过添加项目恢复。操作只影响本机当前服务器的项目可见性，不归档或删除会话，不终止任务或终端，不删除草稿。
- 隐藏路径独立保存在 DataStore；缓存加载、服务器摘要发现与默认工作目录都遵守该设置，刷新或重新启动不自动添加回来。再次添加同一路径会恢复显示。
- 普通 `/tmp` 项目继续正常显示，不增加基于临时目录路径的全局过滤规则。

## 0.1.26：聊天阅读与文件摘要

- 以用户提供的 iOS 截图为视觉层级参考，保留 Android 原生返回、触控、输入法与底部弹层。助手正文使用透明布局，只有用户消息、代码、表格和文件摘要有独立表面。正文保持 15sp / 24sp 的紧凑工作台尺度，段落间距 8dp，行内代码使用更浅的圆角背景。
- 文件摘要明确标注“本轮更改”，默认展示前三个文件，其余可展开。普通文件行优先展示文件名；同名文件加父目录区分，展开后可选择完整路径和查看 diff。diff 默认最多显示 60 行，可继续展开；未知增删量不虚构计数。统计来自本轮文件操作，不代表工作区净差异。
- 完成回复底部提供复制、Android 系统分享，以及已确认轮次的完成提示；不增加没有协议支撑的反馈按钮、耗时数字或工作区总计。长回复以完整 UTF-8 Markdown 文件分享；过长文本不直接塞进剪贴板 Binder 请求，提示使用文件分享。
- 输入区合为两行：附件／输入／语音或发送操作一行，模型与思考强度一行。空草稿时右侧为语音，有内容时显示发送，运行中为停止。输入时仍可通过下方语音按钮补充文本。上传未完成、离线及待确认发送状态沿用原限制。
- 保留既有流式段落复用与参考链接环境缓存，不引入流式布局动画。复制、文件展开等操作有轻触反馈；图标沿用固定版本 Lucide，新增 copy 与 share-2 的上游 SVG。

## 0.1.34：输出过程与同步状态可视化

- 会话输出按“任务结果”和“传输状态”分开表达。运行中的轮次显示“正在接收回复”和实时状态；完成的轮次显示已同步；历史正在与服务端对齐时显示对齐状态；连接中断时显示等待同步，不把网络断开误报为任务失败。
- 执行过程收敛为一个紧凑摘要：状态图标、事件/命令/文件数量和最近四个事件标签在同一层可见。命令、思考、计划和未支持事件仍默认折叠，点击摘要可查看原始过程与失败项。
- 助手正文保留连续 Markdown 文档，不对流式文本添加逐字布局动画。正文标题显示 Codex、任务状态和必要的同步标记；最终回复保持可复制、分享和完整 Markdown 阅读。
- 同步标记使用云端图标和文字，不以颜色或旋转动画作为唯一信息；系统关闭动画时状态文字和图标仍完整可读。输出轨道在窄屏上自动换行，避免遮盖正文。
- 会话中的远端 `localImage` 先以“加载图片预览”占位，下载成功后以内嵌缩略图显示；点击缩略图进入原有全屏查看器，支持适应屏幕、双指缩放和双击重置。重复打开复用本机会话内缓存，不重复下载。
- 官方 App Server 的 `imageView {id, path}` 条目作为图片查看事件解析，不再显示为未知类型；它会直接进入会话图片预览链路，并在执行过程摘要之外保留可见图片。

## 0.1.28：轻量选择弹层

- 模型、思考强度、服务器、项目使用共享 `SelectionList` / `SelectionSheet`；选择值的单选列表与带功能图标的操作菜单分开维护。正常选择弹层不再显示规则介绍；仅在任务运行时显示“用于下一条消息”，空列表和不支持调整的状态保留必要提示。
- 标题 18sp，选项 15sp；标题与行内容共用 24dp 左右边距。单行最小 52dp，整行点击、原生波纹与轻触反馈，使用单选角色和 selected 语义。右侧固定保留 20dp 选中位置，不因勾选改变名称宽度；无卡片边框、重复装饰图标或逐行分割线。
- 模型刷新改为标题右侧 48dp 触控按钮，保留可访问名称；离线时禁用刷新。实际模型与思考强度仍来自服务器，继承设置的行为保持原样。
- 服务器保留名称与连接状态，状态以轻量文字显示；字体倍率 >1.3 或宽度 <360dp 时状态移到名称下方，避免挤压名称。项目默认只显示名称，同名项目附完整路径区分。名称与路径允许换行，不用不可恢复的截断隐藏必要信息。
- 原生底部弹层跳过半展开状态，列表高度随内容变化且限制最大高度；长列表滚动，打开时定位到当前选择附近。系统返回和拖动关闭沿用 Material 行为。项目新增入口保留在项目列表尾部。
- Debug 离线场景 `picker-model`、`picker-effort`、`picker-hosts`、`picker-projects` 使用实际组件，不连接远端、不创建测试会话。

## 0.1.29：图片查看与附件预览

- 远程图片预览使用独立查看器：下载完成后显示，加载中有进度状态，读取失败显示可理解的错误状态；关闭按钮保持固定在安全区内。

## 0.1.30：中性表面层级

- 页面使用 `background → surfaceContainerLow → surfaceContainer → surfaceContainerHigh` 的中性灰阶表达层级，蓝灰色只用于操作、选中和状态。

## 0.1.33：展开引导、背景模糊与输入工具栏

- 项目标题提供持续的轻微选中底色，箭头旋转，前四条会话以 180ms 展开、120ms 收起。初始状态直接呈现，展开过渡可被反向操作打断；遵循 Compose 的系统动画缩放。长历史继续使用 LazyColumn，避免将全部会话纳入高度动画。
- 只在用户点击展开后，使用 BringIntoViewRequester 最小滚动露出项目标题和第一条会话，计算区域包含顶部栏遮挡；拖动列表取消待执行的滚动。后台内容更新不请求滚动，不抢键盘或 TalkBack 焦点。
- 引入 Apache-2.0 的 Haze 1.6.10（与现有 Compose/Kotlin 兼容的固定版本）。首页/聊天滚动内容独立记录为背景源，顶部栏及输入工具栏采样背景并应用 20dp 模糊、68% 中性表面叠色，无噪点；前景文字和图标不被模糊，也不参与背景采样。Android 12/API 31 起使用 RenderEffect；API 29–30 明确使用 97% 表面叠色降级，不宣称旧设备有实时模糊。
- 输入框上方为完整宽度的文字区，最多五行，额外受可用高度的 35%（48–144dp）限制，超出内部滚动。附件仍在文字上方；底部固定上传、模型、思考强度、语音和发送/停止，发送空草稿时禁用，按钮保持 48dp 点击区域。
- 工具栏可用宽度不足 344dp 或字体倍率大于 1.3 时，将模型与思考合为单一入口，弹层中分别进入原有选择器。保持发送、上传、离线和待确认状态的原限制。
- ConversationViewport 为真实聊天和离线预览共用的布局：单一 IME inset 消费点、实测底部操作区高度、列表末尾留白。聊天跟随最新/阅读历史的逻辑沿用，监听实际布局；打字和流式文本不增加逐字布局动画。
