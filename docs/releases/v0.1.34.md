GHub 首个公开版本。通过 SSH 在 Android 上管理 Linux 主机的官方 Codex CLI 会话。

## 功能

- SSH 密钥、密码、键盘交互认证及多级跳板机，首次连接核对主机指纹。
- 项目与会话管理、流式消息、任务状态、模型和思考级别选择、执行审批。
- Markdown、代码、文件变更和图片展示，支持附件上传、拍照及系统语音转文字。
- SFTP 文件浏览、下载、文本编辑，以及交互终端和远端 tmux。
- 本地缓存、草稿、断线恢复，中文和英文界面。

## 安装

下载附件 `ghub.apk`，支持 **Android 10（API 29）及更新版本**。包名为 `dev.remotegpt.app`，版本为 `0.1.34`（versionCode 35），使用长期发布密钥签名。

开发预览版 `dev.remotegpt.preview` 可以与正式版共存。相同包名的 Debug 版因签名不同无法直接覆盖；卸载会清除该版本的本地配置和草稿。

远端需要 Linux、SSH，以及 **Codex CLI / App Server 0.164.0 或更新的 0.x 版本**，并完成登录和 `codex app-server daemon bootstrap`。App Server 仍是实验性接口，具体兼容性以握手和协议行为为准。配置步骤见 [README](https://github.com/iawnix/GHub#使用)。

## 附件与验证

- `ghub.apk`：签名的 Release 安装包。
- `ghub-source.tar.gz`：此标签对应的完整项目源码及第三方许可证。
- `SHA256SUMS`：上述两个文件的 SHA-256 校验和。

发布流程运行 JVM 单元测试、Android Lint，并使用 `apksigner` 验证签名。设备与真实 SSH / daemon 的验证记录及限制见 [验收记录](https://github.com/iawnix/GHub/blob/v0.1.34/docs/verification.md)。本版本不承诺 Android 后台长期保活，离线期间没有即时推送。
