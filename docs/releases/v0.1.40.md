GHub 0.1.40 优化终端布局、快捷键和横屏输入体验。

## 改进

- 点击顶栏终端名称切换会话，选择面板提供新建、关闭和完整项目路径。底部默认只保留 Esc、Tab、Ctrl 与方向键，扩展键盘和字号调整移入菜单，为终端正文留出更多空间。
- Ctrl、Alt、Shift 点按仅影响下一次输入，长按锁定，再次点按解除；切换终端清空修饰状态。快捷键遵循终端应用光标模式，支持 Vim、tmux 和组合方向键。
- 字号支持 10–28sp、双指缩放和恢复默认，字号及扩展键盘设置自动保存。窄屏与大字体下快捷键自动换行，保持足够的触控范围。
- 横屏或短窗口弹出输入法时自动收起部分工具栏，保留隐藏键盘和已激活修饰键入口；修复可见行数不足时光标落到屏幕外的问题。
- 新终端在交互 shell 启动前进入项目目录，消除初始化 cd 命令的重复回显。正确处理带空格、单引号和中文的目录；目录不可用时明确报错退出。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.40`，versionCode `41`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.39`。

本地验证覆盖修饰键单次输入与锁定、中文和 emoji、应用光标模式、320dp / 200% 字体、短窗口光标及终端切换。真实 SSH 测试验证了项目目录引用、PTY 尺寸调整和 Vim / tmux 操作；精简 Release 验证了 SSH、SFTP、项目目录启动与既有界面操作。发布流程还检查 JVM 测试、Android Lint、API 29/35/36 设备回归和 API 35 精简 Release 运行。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。
