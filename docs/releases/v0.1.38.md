GHub 0.1.38 整理服务器设置中的配置、连接和返回逻辑。

## 改进

- 移除服务器设置中的“打开项目”，项目统一从工作台首页进入。连接状态与操作放在同一区域，根据状态显示连接、取消连接、停止重连、断开连接或重试；编辑配置单独放在配置区域。
- 在设置中查看、编辑或连接其他服务器时保留当前工作台，连接与服务初始化操作明确作用于正在管理的服务器。
- 编辑后返回该服务器详情，再逐级返回服务器列表和设置；删除正在查看的服务器后回到列表。
- 保存名称或默认目录时保留现有连接；修改地址、认证、跳板或远端服务参数时释放旧连接，并提示重新连接。离线详情不再展示上次连接的远端环境信息。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.38`，versionCode `39`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.37`。

本地已通过编译、单元测试、Android Lint 和 5 项 API 35 设备检查，覆盖连接按钮状态、管理其他服务器时保留工作台、编辑和删除后的返回路径，以及真实 SSH 会话中改名保持终端、修改连接参数释放旧连接的行为。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。发布由 JVM 测试、Android Lint、API 29/35/36 设备回归和 API 35 精简 Release 运行检查共同把关。
