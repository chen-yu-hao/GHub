GHub 0.1.37 简化终端入口，并改善执行过程展开后的间距。

## 改进

- 进入终端页面后，在连接就绪时自动打开当前项目的首个终端；已有终端直接复用，无需再次点击“新建”。创建时显示进度，同一项目的重复请求共用正在进行的创建操作，断开连接时取消未完成的创建。
- 移除终端底部重复的“工作区”按钮。保留顶部菜单，以及键盘、新建终端和字号调整操作。手动关闭最后一个终端后保持空白，可再次新建或重新进入页面。
- “查看过程”展开后的内容左右各增加 16dp 留白，条目之间增加间距。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.37`，versionCode `38`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.36`。

本地已通过编译、单元测试、Android Lint，以及 API 35 独立 SSH 环境下的终端自动打开、返回复用、重复请求、关闭、Activity 重建和后台重连检查。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。发布由 JVM 测试、Android Lint、API 29/35/36 设备回归和 API 35 精简 Release 运行检查共同把关。
