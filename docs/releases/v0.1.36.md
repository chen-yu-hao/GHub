GHub 0.1.36 修复执行过程收起后仍显示全部失败条目的问题。

## 修复

- 执行过程默认收起时，失败条目也一起折叠，避免大量失败命令占满对话页面。
- 收起后仍保留红色失败数量和简短事件概览；点击执行汇总可展开全部条目并查看详情。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.36`，versionCode `37`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.35`。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。发布由 JVM 测试、Android Lint、API 29/35/36 设备回归和 API 35 精简 Release 运行检查共同把关。
