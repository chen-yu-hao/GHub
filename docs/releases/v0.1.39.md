GHub 0.1.39 改进命令执行、输出日志和代码块的阅读体验。

## 改进

- 命令、输出和执行状态分区展示；工作目录、退出码和耗时采用服务器提供的数据，命令与输出可分别复制原文。
- 命令、审批、回复代码块和 Diff 共用代码阅读组件，提供基础语法高亮、等宽排版和深浅色适配。支持 Shell、JSON、Python、JavaScript/TypeScript、Kotlin/Java、YAML 和 Diff；未知语言保留纯文本。
- 命令和日志默认自动换行，源码和 Diff 默认横向滚动，均可切换。长内容提供全屏阅读器，按段加载；界面排版不改变复制的原文。
- 日志支持常见 ANSI 前景色，Diff 区分文件头、区间信息和增删行。执行过程及失败条目继续支持折叠。
- 流式高亮在后台合并处理并限制扫描量，收起或离开时释放任务；结构化命令纳入历史内存预算。旧缓存保留原始记录入口，截断的缓存输出明确标注。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.39`，versionCode `40`，包名 `dev.remotegpt.app`；沿用正式签名，可覆盖安装 `0.1.38`。

本地验证覆盖命令与输出分别复制、流式追加、失败折叠、旧缓存、Markdown 高亮，以及 320dp / 200% 字体下完整阅读与复制。真实 SSH / Codex 测试验证了 180 行中文失败输出、退出码、重连历史及缓存一致性；非 debuggable 的 R8 Release 验证了实际界面复制、完整输出阅读、加密密钥、SFTP 和终端。发布流程还检查 JVM 测试、Android Lint、API 29/35/36 设备回归和 API 35 精简 Release 运行。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。
