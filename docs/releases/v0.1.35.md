GHub 0.1.35 修复长时间使用时的资源累积，并改善 Android 生命周期、输入和无障碍支持。

## 修复

- 每台主机最多保留 8 个闲置会话，另设约 400 万字符的预算；当前、生成中、审批中及正在同步的会话受保护。淘汰前保存本地缓存，再次打开从缓存和远端恢复，不删除远端会话或未发送草稿。
- 图片预览使用独立磁盘缓存，限制为 64 个文件、100 MiB；单张最大 20 MiB。清除缓存同时清除图片预览，保留附件草稿。
- 未启用后台保持时，进入后台 30 秒后释放 SSH、SFTP 和终端资源，回到前台恢复原连接。短暂旋转屏幕或打开文件选择器不会立即断开。需要断线后保留 shell 任务时请使用远端 tmux。
- SSH 连接关闭在 IO 线程执行；修复终端建立过程中取消操作的资源清理，已完成的缓存写入任务及时移除。
- 服务器表单在 Activity 重建后保留输入；未保存凭据仅保留在进程内，不写入 Android SavedState。进程终止后恢复普通字段，已保存凭据从加密存储读取。
- 未保存的远端文本编辑保存到应用私有目录，恢复原文件校验值以继续检查冲突；关闭编辑器会丢弃该草稿。
- 修复大字体和较高软键盘下多行输入框挤掉底部操作按钮的问题。
- 密码输入使用密码键盘并关闭自动纠正；图片支持可访问的放大、缩小和重置按钮；英文计数使用 Android plurals。
- 拒绝通知权限后仍可启用用户主动请求的前台连接服务，并显示权限影响说明。
- Release 启用 R8 和资源裁剪，保留 SSH / JCA 密码学反射所需类；CI 增加精简 Release 的加密密钥、SFTP 和终端运行检查，以及 Android 16 设备回归。

## 安装与验证

下载 `ghub.apk`，支持 Android 10 及更新版本。版本号 `0.1.35`，versionCode `36`，包名 `dev.remotegpt.app`；沿用上一版正式签名，可覆盖安装 `0.1.34`。

附件包括签名 Release APK、对应源码和 `SHA256SUMS`。发布由 JVM 测试、Android Lint、API 29/35/36 设备回归和 API 35 精简 Release 运行检查共同把关。

本次修复已识别的缓存与生命周期问题，不代表已经证明不存在任何内存泄漏；尚未完成真机长时间堆分析。当前或正在生成的超大会话仍可占用较多内存，Android 系统也可能回收后台进程。
