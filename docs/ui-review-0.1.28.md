# 选择面板设计记录（0.1.28）

模型、思考级别、服务器和项目选择统一使用 `SelectionList` / `SelectionSheet`。这次调整的目标是让选项、当前选择和必要的辅助信息保持一致的位置。

| 调整 | 设计依据 |
|---|---|
| 正常状态直接显示选项，运行中显示「用于下一条消息」 | 提示与用户当前决策相关 |
| 刷新按钮移至标题右侧 | 列表集中呈现可选项 |
| 最小 52dp 行高、24dp 左右边距、固定 20dp 勾选位置 | 保持触控范围和对齐 |
| 服务器名称与状态在窄屏、大字体下分行 | 长名称保持可读 |
| 同名项目附路径，其他项目显示名称 | 提供必要的区分信息 |

检查覆盖中英文、深浅色、320dp / 200% 字体、长列表与选择语义；当时的 3 项设备回归通过。触感和 TalkBack 朗读留给真机体验检查。

后续交互约定见[界面设计](ui-design.md)，组件入口见[开发指南](development.md)。
